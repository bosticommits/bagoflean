# Reference board

Pictures of products the owner likes (screenshots from Etsy, Pinterest, shops). The image files
are gitignored (they belong to other shops, and this repo is public); the notes below are the record.
One file per
picture, plus one line per picture below: what the owner likes about it.

How it works:
1. The owner sends the pictures in the chat.
2. They're saved here as `YYYY-MM-DD-short-name.png`, and a line goes into the table below.
3. The designer and researcher look at them before each round, borrow the idea (layout, colours,
   type, photo style, level of detail), never the artwork or the words, and add general lessons
   to `knowledge/design-playbook.md` (section 6).
